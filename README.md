# Portfolio

A personal portfolio site — dark, blue, minimal, built to look at home next to a GitHub profile.

**Live site:** add your GitHub Pages link here once it's published (e.g. `https://your-username.github.io/`)

## About

I'm a Roblox and Minecraft developer, not a software engineer. I build military roleplay systems in Roblox Studio and run Minecraft servers, and I currently serve as Minister of National Defence for Cambodia Army Roleplay.

This site covers:
- **Projects** — bases, systems and servers I've built
- **Command experience** — leadership roles held, current and past
- **Current posting** — click the card on the homepage for a full breakdown of the role, its divisions, and screenshots
- **About** — background and tools
- **Contact** — Discord, Roblox profile, and email

## Structure

Single self-contained file: `index.html`. No build step, no dependencies to install — open it directly in a browser or serve it as-is.

- `.nojekyll` — tells GitHub Pages to serve the file as-is instead of running it through Jekyll

## Editing

Open `index.html` in any text editor. Content — name, project descriptions, dates, division names, screenshots — sits near the top of the body, clearly separated from the styling above it.

## Deployment

Hosted with GitHub Pages. Pushing changes to the `main` branch updates the live site automatically within a minute or two.
